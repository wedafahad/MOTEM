# نشر موقع "متم" على GitHub + Google Sheets

هذا الدليل يشرح كيف تنقلين الموقع من تخزين Claude إلى قاعدة بياناتك الخاصة (Google Sheets)، وتستضيفين الموقع مجاناً على GitHub Pages — يشتغل لأي شخص، من أي جهاز، بدون شرط باقة أو حساب Claude.

**الوقت المتوقع:** 15-20 دقيقة، مرة واحدة فقط.

---

## الجزء الأول: قاعدة البيانات (Google Sheets)

### 1. أنشئي شيت جديد
- روحي إلى https://sheets.google.com
- "+ إنشاء شيت جديد" (Blank spreadsheet)
- سمّيه مثلاً "متم - قاعدة البيانات"

### 2. افتحي محرر السكربت
- من القائمة العلوية: **Extensions ← Apps Script** (الإضافات ← Apps Script)
- بيفتح لك تبويب جديد فيه محرر أكواد

### 3. الصقي الكود
- امسحي أي كود موجود افتراضياً (`function myFunction() {}`)
- افتحي ملف **Code.gs** المرفق معك، انسخي محتواه كاملاً، والصقيه في المحرر
- احفظي (أيقونة الفلوبي/`Ctrl+S`)، وسمّي المشروع "متم-تخزين" أو أي اسم

### 4. انشريه كـ Web App
- زر **Deploy ← New deployment** (نشر ← نشرة جديدة) — أعلى يمين الصفحة
- اضغطي أيقونة الترس ⚙️ بجانب "Select type" واختاري **Web app**
- الإعدادات:
  - **Execute as:** Me (حسابك)
  - **Who has access:** **Anyone** (مهم جداً — لو اخترتِ غيرها الموقع ما بيقدر يوصل للبيانات)
- اضغطي **Deploy**
- أول مرة، جوجل بيطلب منك صلاحية (Authorize access) — وافقي، واختاري حسابك، واضغطي "Advanced ← Go to [اسم المشروع] (unsafe)" ثم "Allow" (هذا تحذير عادي لأي سكربت شخصي جديد، طبيعي وآمن لأنه سكربتك انتي).
- بعد النشر، بيطلع لك **رابط Web App** يبدأ بـ:
  `https://script.google.com/macros/s/xxxxxxxxxxxx/exec`
- **انسخي هذا الرابط بالكامل** — بتحتاجينه بالخطوة الجاية.

> ⚠️ إذا عدّلتِ كود Code.gs لاحقاً، لازم تسوين **Deploy ← Manage deployments ← ✏️ تعديل ← نسخة جديدة (New version) ← Deploy** عشان التعديل ينعكس. الرابط نفسه ما يتغيّر.

## الجزء الثاني: ربط الموقع بالرابط

- افتحي ملف **index.html** المرفق معك (بأي محرر نصوص، حتى Notepad أو TextEdit يكفي)
- دوري (Ctrl+F / Cmd+F) عن:
  ```
  const APPS_SCRIPT_URL = 'PASTE_YOUR_WEB_APP_URL_HERE';
  ```
- استبدلي `PASTE_YOUR_WEB_APP_URL_HERE` برابط الـ Web App اللي نسختيه، فيصير مثلاً:
  ```
  const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/xxxxxxxxxxxx/exec';
  ```
- احفظي الملف.

---

## الجزء الثالث: النشر على GitHub Pages

### 1. أنشئي حساب GitHub (لو ماعندك)
https://github.com/signup — مجاني

### 2. أنشئي Repository جديد
- زر **+ ← New repository** أعلى يمين الصفحة
- اسم مقترح: `kenayah-mutamm`
- خليه **Public**
- **Create repository**

### 3. ارفعي ملف index.html
- من صفحة الـ Repository: **Add file ← Upload files**
- اسحبي ملف `index.html` (بعد ما عدّلتيه بالجزء الثاني) وأفلتيه
- **Commit changes**

### 4. فعّلي GitHub Pages
- من تبويب **Settings** بالـ Repository ← **Pages** (بالقائمة الجانبية)
- تحت **Branch**: اختاري `main` والمجلد `/ (root)` ← **Save**
- انتظري دقيقة أو دقيقتين، ثم حدّثي الصفحة — بيطلع لك رابط أعلى الصفحة مثل:
  `https://your-username.github.io/kenayah-mutamm/`

**هذا هو الرابط النهائي اللي توزعينه على الفريق.** يشتغل لأي شخص بدون حساب Claude، بدون شرط باقة، من الجوال أو الكمبيوتر.

## اختبار سريع

1. افتحي الرابط الجديد
2. سجّلي دخولك كأي كاتب (بنفس الأكواد القديمة)
3. أضيفي عمل تجريبي
4. لو ظهرت "تمت الإضافة" فوراً — نجح الربط ✅
5. للتأكيد: افتحي الـ Google Sheet نفسه، لازم تشوفين ورقة اسمها "Storage" فيها صف جديد باسم المفتاح `tasks:...`

## لو صار خطأ

- **"فشل الحفظ" رغم كل الخطوات**: تأكدي إن "Who has access" فعلاً **Anyone** مو "Only myself" بإعدادات النشر (الخطوة 4 بالجزء الأول).
- **الصفحة بيضاء أو ما تفتح**: تأكدي إن اسم الملف بالضبط `index.html` (حساس لحالة الأحرف).
- **تعديل مستقبلي على السكربت ما ينعكس**: لازم "نسخة جديدة" (New version) وقت النشر، مو نفس النسخة القديمة.
- أي خطأ تاني، انسخي رسالة الخطأ (لو ظهرت بـ Developer Console بالمتصفح: F12 ← Console) وابعتيها لي.
